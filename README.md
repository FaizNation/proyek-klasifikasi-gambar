## Deskripsi
Klasifikasi gambar 10 jenis hewan (dog, horse, elephant, butterfly, chicken, cat, cow, sheep, spider, squirrel) menggunakan CNN dengan Keras Sequential (Conv2D dan MaxPooling2D).

## Dataset
- Sumber: [Animals-10 (Kaggle, viratkothari/animal10)](https://www.kaggle.com/datasets/viratkothari/animal10), berasal dari dataset alessiocorrado99.
